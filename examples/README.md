# Примеры Lua

[Главная](../README.md) · [Быстрый старт](../docs/getting-started.md) · [Справочник](../docs/reference.md)

| Файл | Назначение |
| --- | --- |
| [01_hello_world.lua](01_hello_world.lua) | Сообщения при загрузке и выгрузке |
| [02_overlay.lua](02_overlay.lua) | Флажок в меню и небольшая плашка на экране |
| [03_menu_events.lua](03_menu_events.lua) | Сообщения при открытии и закрытии меню |

Скопируй выбранный файл в `C:\neverwin\scripts`, обнови список Extensions
и загрузи его. Либо вставь код в скрипт через встроенный редактор.

Примеры используют API из справочника и не требуют Allow Insecure.
Они подготовлены как минимальные примеры; запуск в игре ещё не проверен.
